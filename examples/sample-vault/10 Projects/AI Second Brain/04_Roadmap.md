# Roadmap (sample)

## 0. Current delivery order

1. Local model only: answers come from a model on the owner's own machine.
2. Failure capture: a wrong or incomplete answer is kept locally for the weekly review.
3. Rented EU compute for questions whose data classification allows it.

Training vocabulary the assistant must answer from:
- A tempo session is a sustained run at marathon pace or faster, usually 20 to 40 minutes.
- An easy run stays in heart-rate zone 2 and should feel conversational.
- A long run is the week's longest run, at easy pace.

## 1. Earlier plan (superseded)

The first plan started with a hosted model. It was dropped: data left the owner's machine
before anyone could check its classification.
